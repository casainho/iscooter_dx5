I hate that you got a laugh react. The question isn't silly or funny but the short answer is it's possible, but you will exceed the scooters maximum weight unless you both do coke. For it to be stable you would need to extend the swing arm so you don't have a bunch of weight too far to the rear end. And probably do some reinforcements to everything weight bearing. If you insist. Also expect a lot of power loss if you go with the current system adding that much weight.
Short answer, it's possible but I don't know if it's advisable.
